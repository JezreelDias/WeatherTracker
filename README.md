# Yosemite Weather Tracker

A weather data tracker for Yosemite National Park that retrieves historical and forecasted temperature data to help identify potential camping conditions.

The project collects:

- **Historical Weather:** Five years of historical temperature data.
- **Weather Forecast:** A seven-day temperature forecast using Open-Meteo.
- **Data Export:** Saves historical and forecast data to two separate CSV files.
- **Console Output:** Prints retrieved weather data for easy viewing.

The collected temperature data can be used to examine seasonal weather patterns and identify periods that may be suitable for camping, based on approximate target temperatures of 70°F during the day and 50°F at night.
